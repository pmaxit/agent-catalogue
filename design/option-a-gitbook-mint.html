Delegating draft without soft exits

Delegate like you mean it. If an agent can say “I’ll skip for now,” you didn’t build a delegation system — you built a suggestion box.

Soft exit: any path where the agent returns without a file, a trace, and a score. Ban it in the prompt, enforce it in the judge.
