Capabilities

What Quill takes off your plate

Four agents. One config file. A quality bar you define.

YAML-defined agents

Names, models, prompts, graph edges, and thresholds live in config/agents.yaml — not buried in code.

Closed quality loop

The manager revises until every criterion clears its threshold — or you hit the iteration ceiling with a clear report.

Theme-driven voice

Pick a writing goal and narrative theme; tone and format flow into the writer and evaluator prompts automatically.

Cursor Cloud Agents

Runs against the Cursor Agents API — or mock mode locally when no key is set, so the UI stays exerciseable.
